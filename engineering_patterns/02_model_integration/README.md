# Model Integration

**Category:** `02_model_integration`  
**Purpose:** Integrate and compare model providers, routing, streaming, and capability normalization.

This category is independent of the other numbered categories. Its patterns
can be used on their own or composed in a larger application.

**Published example:** [Basic API Integration](basic_api_integration/README.md) provides a
provider-neutral offline/mock or opt-in OpenAI Responses API demonstration.
Streaming, async, and routing are intentionally deferred.

**Typed-decision example:** [Jev typed decisions](jev_typed_decisions/README.md)
demonstrates TypeSafe's Jev System One API through both its Python SDK and its
direct HTTP contract, while keeping routing policy in ordinary application code.

See the [shared pattern template](../_template/README.md).
