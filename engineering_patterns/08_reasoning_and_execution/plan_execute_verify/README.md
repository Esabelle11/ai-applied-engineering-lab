# Iterative independent verification

## Problem and context
Illustrate a reusable reasoning and execution engineering capability without paid API calls. The example uses deterministic offline data and the shared `applied_ai` SDK.

## Mechanism and implementation
A deterministic solver-verifier loop checks each answer against an independent arithmetic calculation and sends bounded feedback when verification fails.

## Run offline

```bash
uv run --locked python engineering_patterns/08_reasoning_and_execution/plan_execute_verify/run.py
```

## Alternatives and tradeoffs
This does not run arbitrary Python generated by a model. The real isolated Python sandbox is a separate security project. A weak or incorrect verifier can accept wrong answers.

## Failure modes
Invalid configuration or unsupported capabilities raise exceptions. No hidden network calls, retries or quality guarantees are introduced in these demonstrations. Refer to the runnable tests for the negative paths.

## Validation and comparison
- Contract, success and failure tests: `tests/test_patterns.py`.
- No measured performance comparison is claimed.
- CLI example should run without credentials after project installation.

## Reuse
Uses canonical code in `src/applied_ai/` rather than maintaining duplicate implementation logic in the handbook.
